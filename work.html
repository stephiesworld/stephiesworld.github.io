Studio Felix

Projects for AI adoption, with the goal of training teams to work with agents.

prototypes

Cherry ↗

Voice-of-customer triage.

how it works
build
Claude via the Anthropic API, searching the open web — reviews, forums, Reddit, news. Feedback flows browser → backend → Claude; nothing stored.
logic
Clusters raw feedback into issues, then ranks by a weighted signal — severity, then reach, then recency. Your corrections re-rank it.

cherry-topaz.vercel.appanthropic api

offramp ↗

Personal finance, debriefed.

how it works
build
Static HTML and JS — the parser, the stats, and the whole rules engine run in the browser; no server, no account, no dependencies. Optional second opinion through the Anthropic API, on your own key, summary only.

getofframp.vercel.appeval loop · client-side

Loop ↗

The org-wide feedback loop, as a product.

how it works
build
Interactive product prototype — one self-contained web app · designed and built with Claude · editorial UI · CVD-validated chart palette.
logic
Nine channels (support, field, early access, in-product) → one system of record. Seven personalized role views, from support triage to a 90-second exec brief. Praise travels the same pipes as complaints; every closed loop ends in ‘you asked, we shipped.’ Guided demo story + phased scale plan built in.

loop-vox.vercel.appinternal tools · prototype

Portraits ↗

Live data storytelling.

how it works
build
Next.js + Framer Motion, drawing on live public feeds — NASA, USGS, NOAA, NYISO, Citi Bike, the NWS — proxied server-side with caching and graceful fallbacks. Real coastlines, charts, and gauges hand-built in SVG; no database, no keys.
logic
One page, three portraits at three scales: the world this second, a single human life, a city over a day. Every square is a true number, live — click one to fall into the story behind it.

portraits-mu.vercel.applive public data

Henry ↗

Amazon 1P vendor operations.

how it works
build
Next.js + Claude with web-search tool use, server-side. Agentic tool-calling for chat and research; deterministic code for the financial math.
logic
True net PPM per ASIN (co-op, freight, chargebacks, returns, ads); classifies chargebacks by root cause and drafts the dispute. Graded by evals.

henry-ten.vercel.appanthropic api · keepa

Stanley ↗

Calendar agent.

how it works
build
Google Calendar read/write, over Telegram with voice. The write is gated in code, not the model.
logic
Reads the week’s schedule and proposes one-line fixes; never acts without confirmation. Learns preferences as seasonal probabilities.

stanley-butler.vercel.apptelegram · voice
